# 🎯 CS2 Triggerbot + Aimbot + ESP

> **Образовательный проект** по взаимодействию с памятью CS2 на Python.

## ✨ Возможности

- **Aimbot** – наведение в голову с настройкой FOV (10-180°) и плавности (Smooth 1-20)
- **Triggerbot** – авто-огонь по врагам
- **Skeleton ESP** – отображение скелетонов, здоровья и дистанции (враги – красные, свои – зеленые)

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `CTRL` | Aimbot ON/OFF |
| `ALT` | Triggerbot ON/OFF |
| `↑/↓` | Smooth (1-20) |
| `←/→` | FOV (10-180°) |
| `END` | Выход |

## 📦 Установка

```bash
pip install pymem pynput pywin32
python triggerbot.py
```

## ⚙️ Настройки

```python
AIM_FOV = 60            # Угол обзора
AIM_SMOOTH = 3          # Плавность (1=мгновенно)
AIM_BONE = 0            # 0=голова
ESP_ENABLED = True      # Скелетоны
```
